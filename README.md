# Excel Minor Project – Sales Operations Analytics

## Project Overview
This project focuses on analyzing sales operations data using Microsoft Excel. It involves working with order records, customer information, product details, sales representatives, and monthly sales targets to solve real-world business questions.

## Objectives
- Perform data lookup operations across multiple worksheets.
- Identify duplicate records, missing references, and data quality issues.
- Calculate revenue and analyze sales performance using conditional aggregation.
- Summarize sales data using PivotTables.
- Apply advanced Excel functions to rank sales representatives and identify business insights.

## Dataset
The workbook contains the following sheets:
- **Orders:** Order details, payments, discounts, and revenue.
- **Customers:** Customer information and segments.
- **Products:** Product categories, prices, costs, and active status.
- **Sales_Reps:** Sales representative details and regions.
- **Targets:** Monthly sales targets for representatives.

## Excel Skills Used
- VLOOKUP and INDEX-MATCH
- SUMIFS, COUNTIFS, and AVERAGEIFS
- IF and nested IF statements
- Data cleaning and quality checks
- PivotTables and percentage analysis
- RANK.EQ, LARGE, INDEX-MATCH, and TEXTJOIN
- Sales performance and revenue analysis

## Project Outcome
The project demonstrates practical Excel skills for data cleaning, business analysis, sales reporting, and decision-making.
